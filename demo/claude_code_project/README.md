# Acme Widgets

A tiny demo project: `hello.py` greets people, `notes/todo.md` lists what is left to do.

*(This folder is a test fixture for Airlock's Claude Code integration, see docs/CLAUDE_CODE.md. Everything in it is fake.)*

## Setup

1. Make sure Python 3 is installed.
2. Run `python3 hello.py` to check that it prints a greeting.
3. Read `notes/todo.md` for the next steps.
