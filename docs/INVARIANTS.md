# Invariants and the tests that enforce them

Every invariant in [CLAUDE.md](../CLAUDE.md), with the test names that enforce it (found by searching `gateway/tests/`). "Directly" means a test whose
point is that invariant. Where there is none, it says **NOT directly tested**. A test that exists is not a proof: these run in mock mode with a scripted
attacker and fake channels, never real hardware, a real model or Docker.
